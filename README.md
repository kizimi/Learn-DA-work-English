# DA English 📊

> Data Analyst 国际团队英语口语学习网站

专为**中文母语 Data Analyst** 打造，帮助你在国际化团队中自信开口说英语。涵盖日常沟通到 Presentation 的全场景表达，配合游戏闯关强化记忆。

🌐 **在线访问：** [kizimi.github.io/Learn-DA-work-English](https://kizimi.github.io/Learn-DA-work-English/)

---

## 功能特点

### 📖 6 大学习模块（48 个核心表达）

| 模块 | 类型 | 内容 |
|------|------|------|
| 澄清需求 | 日常沟通 | 取数前对齐需求、确认维度和时间范围 |
| 描述数据与趋势 | 日常沟通 | 描述峰值、趋势、相关性、同比环比 |
| 跨团队协作 | 日常沟通 | 和 Engineering / Product / Marketing 日常沟通 |
| 解释异常 & 回应质疑 | 日常沟通 | 数据归因、说明局限、专业回应质疑 |
| 会议汇报 | Presentation | 开场引导、切换话题、总结收尾 |
| 推动决策 | Presentation | 给出建议、量化影响、推动 stakeholder 决策 |

每个表达卡片包含：
- 英文句型（可替换部分高亮标注）
- 中文释义
- 真实工作场景例句
- 使用小贴士

### 🎮 每日闯关游戏

- **每日 5 题**，根据日期自动生成，每天不重样
- **3 种题型**混合：情景选词 / 句子填空 / 中英配对
- **即时反馈**：答对答错立即显示，附知识点解释
- **再来 5 题**：完成后可继续挑战，题库共 30 题轮换
- **连续打卡**：记录每日学习 streak

### 📒 错题本

- 答错的题目**自动保存**，重复答错累计错误次数
- 显示你的错误答案与正确答案对比
- 附知识点解释，针对性复习
- 支持标记「已掌握」或清空全部

---

## 技术实现

- 纯静态 HTML / CSS / JavaScript，零依赖
- 使用 `localStorage` 持久化打卡记录和错题数据
- 题目每日轮换基于日期种子的伪随机算法
- 部署于 GitHub Pages
